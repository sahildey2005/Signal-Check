Understand the result

Signal Check runs two independent headline classifiers. Their outputs answer different questions and should never be treated as a single verdict.

Clickbait is about presentation

Clickbait wording is designed to attract attention or encourage a click. A headline can be clickbait and still describe a true event. A neutral-sounding headline can also contain a false claim.

Fake/true labels are dataset labels

The second model compares a headline with examples labelled fake or true in the supplied training files. These inherited labels are not an independent fact-check of the headline you enter.

How the machine-learning pipeline works

  1. Training data is read from the supplied CSV files.
  2. Headlines are cleaned and converted into word, two-word phrase, and writing-style features.
  3. Two Multinomial Naive Bayes classifiers learn patterns from their own labelled datasets.
  4. The trained weights and evaluation results are saved in models.json.
  5. This browser app loads those saved values and predicts on the headline you enter. It also keeps a cautious self-learning memory of very high-confidence clickbait predictions on this browser and uses similar past patterns to make a limited adjustment to later checks.

Technology used

Python standard library for data preparation and model training; HTML, CSS and JavaScript for the browser interface; JSON for storing the trained model parameters.

Limitations and responsible use

  • A headline alone is not enough to establish whether an article or claim is true.
  • The model can learn topic, publisher, time-period, and dataset-label patterns rather than factual accuracy.
  • Holdout metrics describe performance on a reserved portion of the supplied datasets. They do not guarantee performance on current news or unfamiliar sources.
  • Model scores are estimates of similarity to learned labels, not verified real-world probabilities. The local learning memory uses the model's own high-confidence predictions as provisional labels, so it can reinforce mistakes and is not a substitute for verified training data.
  • The self-learning memory stays in this browser's local storage; it is not uploaded or shared. Clearing this browser's site data removes it.
  • Always read the full article, check its date and original sources, and compare independent reporting before sharing a claim.
